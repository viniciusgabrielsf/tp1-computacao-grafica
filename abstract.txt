  📋 Próximo Passo - Instalar GLAD:

  O GLAD é a única dependência que precisa ser configurada manualmente:

  Opção 1 - Script Automático:
  ./install_glad.sh

  Opção 2 - Manual:
  1. Acesse: https://glad.dav1d.de/
  2. Configure: OpenGL 3.3+, Core Profile
  3. Baixe e extraia em external/glad/

  Guia detalhado: Veja SETUP.md

  🚀 Compilar e Executar:

  # Instalar dependências (macOS)
  brew install cmake glfw glm

  # Compilar
  mkdir build && cd build
  cmake ..
  make

  # Executar
  ./BoidsSimulation
